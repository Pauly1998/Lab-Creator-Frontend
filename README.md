# LabCreator frontend demo

A responsive multi-page static frontend built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `labcreator-frontend` folder in VS Code.
3. Install the **Live Server** extension (Ritwick Dey).
4. Right-click `index.html` and choose **Open with Live Server**.
5. The site opens in your browser. Use the navigation to visit the other pages.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Pages
- `index.html` – homepage
- `products.html` – searchable and filterable product catalogue
- `product.html` – product details (opened from a product card)
- `services.html` – services and capabilities
- `about.html` – company overview
- `projects.html` – project gallery
- `clients.html` – client/partnership page
- `how-we-work.html` – process page
- `faq.html` – expandable FAQs
- `blog.html` – resource cards
- `contact.html` – validated enquiry form demo
- `privacy.html` – sample privacy page

## Folder structure
- `assets/css/style.css` – all styling and responsive rules
- `assets/js/data.js` – product, service, project and FAQ content
- `assets/js/main.js` – shared header/footer, rendering, filters and interactions

## Important before publishing
This is an original frontend implementation inspired by the public page structure and content themes of labcreator.in; it is not their source code and does not reuse their logo or proprietary assets. Replace sample imagery with assets you have permission to use. Verify all company information and claims. The contact form currently validates in the browser but does **not** send email or save enquiries; connect a backend/API or form provider before using it for real leads. Product names/descriptions are starter content; verify specifications with the business.
